# @iconify-vue/fluent

**Fluent UI System Icons**

Author: [Microsoft Corporation](https://github.com/microsoft/fluentui-system-icons)

License: [MIT](https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE)

Browse all icons: [preview Fluent UI System Icons on Iconify](https://icon-sets.iconify.design/fluent/)

## Installation

```bash
npm install github:iconify/icons-vue#fluent
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fluent/zoom-out-24-filled';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fluent/drink-coffee-24-regular';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fluent/photo-filter-24-regular';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
