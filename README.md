## Installation

```bash
npm install gitlab:iconify-icons/vue#selfhst
```

or
```bash
npm install github:iconify/icons-vue#selfhst
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/selfhst/salt';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/selfhst/adobe';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
