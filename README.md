# @iconify-vue/heroicons-outline

**HeroIcons v1 Outline**

Author: [Refactoring UI Inc](https://github.com/tailwindlabs/heroicons)

License: [MIT](https://github.com/tailwindlabs/heroicons/blob/master/LICENSE)

Browse all icons: [preview HeroIcons v1 Outline on Iconify](https://icon-sets.iconify.design/heroicons-outline/)

## Installation

```bash
npm install github:iconify/icons-vue#heroicons-outline
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/heroicons-outline/color-swatch';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/heroicons-outline/library';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/heroicons-outline/receipt-refund';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
