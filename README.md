License: **MIT**

Repository: **https://github.com/icons8/flat-Color-icons**

Browse all icons: **[Preview Flat Color Icons](https://icon-sets.iconify.design/flat-color-icons/)**

## Installation

```bash
npm install github:iconify/icons-vue#flat-color-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/flat-color-icons/edit-image';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/flat-color-icons/donate';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
