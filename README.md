# @iconify-vue/gcp

Icon set prefix: **gcp**

Icon set name: **Google Cloud Icons**

Author: **Google Cloud**

License: **[Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)**

Browse all icons: **[Preview Google Cloud Icons](https://icon-sets.iconify.design/gcp/)**

## Installation

```bash
npm install github:iconify/icons-vue#gcp
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/gcp/filestore';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/gcp/trace';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
