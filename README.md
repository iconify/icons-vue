Browse all icons: [preview Iconoir on Iconify](https://icon-sets.iconify.design/iconoir/)

## Installation

```bash
npm install github:iconify/icons-vue#iconoir
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconoir/chat-bubble-check';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconoir/edit';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconoir/activity';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
