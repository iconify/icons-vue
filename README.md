**Nonicons**

Author: [yamatsum](https://github.com/yamatsum/nonicons)

License: [MIT](https://github.com/yamatsum/nonicons/blob/master/LICENSE)

Browse all icons: [preview Nonicons on Iconify](https://icon-sets.iconify.design/nonicons/)

## Installation

```bash
npm install github:iconify/icons-vue#nonicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nonicons/kotlin-16';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nonicons/vue-16';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nonicons/npm-16';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
