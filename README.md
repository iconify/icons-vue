Browse all icons: [preview Jam Icons on Iconify](https://icon-sets.iconify.design/jam/)

## Installation

```bash
npm install github:iconify/icons-vue#jam
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/jam/chevrons-square-up-right';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/jam/luggage-f';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/jam/rubber';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
