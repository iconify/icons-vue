## Installation

```bash
npm install gitlab:iconify-icons/vue#at-icons
```

or
```bash
npm install github:iconify/icons-vue#at-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/at-icons/shield';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/at-icons/checkerboard';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/at-icons/ladder';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
