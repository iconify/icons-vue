Browse all icons: [preview Majesticons on Iconify](https://icon-sets.iconify.design/majesticons/)

## Installation

```bash
npm install github:iconify/icons-vue#majesticons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/majesticons/chats-line';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/majesticons/home';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/majesticons/edit-pen-4-line';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
