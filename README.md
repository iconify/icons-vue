Browse all icons: [preview Tabler Flags on Iconify](https://icon-sets.iconify.design/tabler-flags/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#tabler-flags
```

or
```bash
npm install github:iconify/icons-vue#tabler-flags
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/tabler-flags/aland-islands';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/tabler-flags/japan';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
