Author: [Corey Ginnivan](https://github.com/CoreyGinnivan/system-uicons)

License: [Unlicense](https://github.com/CoreyGinnivan/system-uicons/blob/master/LICENSE)

Browse all icons: [preview System UIcons on Iconify](https://icon-sets.iconify.design/system-uicons/)

## Installation

```bash
npm install github:iconify/icons-vue#system-uicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/system-uicons/bell';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/system-uicons/message-writing';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/system-uicons/write';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
