## Installation

```bash
npm install gitlab:iconify-icons/vue#lucide
```

or
```bash
npm install github:iconify/icons-vue#lucide
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide/circle-check';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide/award';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide/house';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
