Browse all icons: [preview Map Icons on Iconify](https://icon-sets.iconify.design/map/)

## Installation

```bash
npm install github:iconify/icons-vue#map
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/map/restaurant';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/map/real-estate-agency';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/map/wheelchair';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
