**Flag Icons**

License: [MIT](https://github.com/lipis/flag-icons/blob/main/LICENSE)

Browse all icons: [preview Flag Icons on Iconify](https://icon-sets.iconify.design/flag/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#flag
```

or
```bash
npm install github:iconify/icons-vue#flag
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/flag/fr-1x1';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/flag/de-1x1';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
