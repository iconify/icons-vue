Browse all icons: **[Preview Eva Icons](https://icon-sets.iconify.design/eva/)**

## Installation

```bash
npm install github:iconify/icons-vue#eva
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/eva/droplet-off-outline';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/eva/flash-fill';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/eva/printer-outline';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
