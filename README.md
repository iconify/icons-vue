Browse all icons: [preview Memory Icons on Iconify](https://icon-sets.iconify.design/memory/)

## Installation

```bash
npm install github:iconify/icons-vue#memory
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/memory/chart-bar';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/memory/application';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/memory/message';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
