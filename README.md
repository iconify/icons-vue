# @iconify-vue/mynaui

**Myna UI Icons**

Author: [Praveen Juge](https://github.com/praveenjuge/mynaui-icons)

License: [MIT](https://github.com/praveenjuge/mynaui-icons/blob/main/LICENSE)

Browse all icons: [preview Myna UI Icons on Iconify](https://icon-sets.iconify.design/mynaui/)

## Installation

```bash
npm install github:iconify/icons-vue#mynaui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mynaui/signal';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mynaui/power';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mynaui/tree';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
