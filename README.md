# @iconify-vue/marketeq

**Marketeq**

Author: Marketeq

License: MIT

Browse all icons: [preview Marketeq on Iconify](https://icon-sets.iconify.design/marketeq/)

## Installation

```bash
npm install github:iconify/icons-vue#marketeq
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/marketeq/mute';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/marketeq/desk-6';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
