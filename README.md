Browse all icons: **[Preview FormKit Icons](https://icon-sets.iconify.design/formkit/)**

## Installation

```bash
npm install github:iconify/icons-vue#formkit
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/formkit/checkbox';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/formkit/reorder';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/formkit/submit';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
