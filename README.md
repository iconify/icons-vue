**Streamline**

Author: [Streamline](https://github.com/webalys-hq/streamline-vectors)

Browse all icons: [preview Streamline on Iconify](https://icon-sets.iconify.design/streamline/)

## Installation

```bash
npm install github:iconify/icons-vue#streamline
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline/sign-hashtag';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline/open-umbrella-solid';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline/graph-bar-increase';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
