Author: **Boxicons**

License: **[MIT](https://github.com/box-icons/boxicons/blob/main/LICENSE)**

Repository: **https://github.com/box-icons/boxicons**

Browse all icons: **[Preview BoxIcons v2 Solid](https://icon-sets.iconify.design/bxs/)**

## Installation

```bash
npm install github:iconify/icons-vue#bxs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bxs/edit-alt';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bxs/tree-alt';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bxs/circle-half';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
