Browse all icons: **[Preview Feather Icons](https://icon-sets.iconify.design/feather/)**

## Installation

```bash
npm install github:iconify/icons-vue#feather
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/feather/check-circle';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/feather/award';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/feather/home';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
