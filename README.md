Browse all icons: [preview Lucide Lab on Iconify](https://icon-sets.iconify.design/lucide-lab/)

## Installation

```bash
npm install github:iconify/icons-vue#lucide-lab
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide-lab/venn';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide-lab/card-credit';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide-lab/pac-man';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
