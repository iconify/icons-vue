Browse all icons: **[Preview Glyphs Poly](https://icon-sets.iconify.design/glyphs-poly/)**

## Installation

```bash
npm install github:iconify/icons-vue#glyphs-poly
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/glyphs-poly/mouse-2';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/glyphs-poly/object-select';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
