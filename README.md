# @iconify-vue/fxemoji

Icon set prefix: **fxemoji**

Icon set name: **Firefox OS Emoji**

Author: **Mozilla**

License: **[Apache 2.0](https://mozilla.github.io/fxemoji/LICENSE.md)**

Repository: **https://github.com/mozilla/fxemoji**

Browse all icons: **[Preview Firefox OS Emoji](https://icon-sets.iconify.design/fxemoji/)**

## Installation

```bash
npm install github:iconify/icons-vue#fxemoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fxemoji/foxweary';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fxemoji/loveletter';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
