# @iconify-vue/gravity-ui

**Gravity UI Icons**

Author: [YANDEX LLC](https://github.com/gravity-ui/icons/)

License: [MIT](https://github.com/gravity-ui/icons/blob/main/LICENSE)

Browse all icons: [preview Gravity UI Icons on Iconify](https://icon-sets.iconify.design/gravity-ui/)

## Installation

```bash
npm install github:iconify/icons-vue#gravity-ui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/gravity-ui/magnifier';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/gravity-ui/bookmark-fill';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/gravity-ui/display';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
