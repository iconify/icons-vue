Browse all icons: [preview Subway Icon Set on Iconify](https://icon-sets.iconify.design/subway/)

## Installation

```bash
npm install github:iconify/icons-vue#subway
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/subway/call-2';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/subway/power-batton';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/subway/admin';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
