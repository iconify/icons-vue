Browse all icons: [preview Pixelarticons on Iconify](https://icon-sets.iconify.design/pixelarticons/)

## Installation

```bash
npm install github:iconify/icons-vue#pixelarticons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pixelarticons/home';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pixelarticons/arrows-horizontal';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pixelarticons/heart';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
