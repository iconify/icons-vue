Browse all icons: [preview Weather Icons on Iconify](https://icon-sets.iconify.design/wi/)

## Installation

```bash
npm install github:iconify/icons-vue#wi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wi/day-hail';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wi/barometer';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wi/day-windy';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
