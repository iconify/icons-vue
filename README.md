# @iconify-vue/healthicons

**Health Icons**

Author: [Resolve to Save Lives](https://github.com/resolvetosavelives/healthicons)

License: [MIT](https://github.com/resolvetosavelives/healthicons/blob/main/LICENSE)

Browse all icons: [preview Health Icons on Iconify](https://icon-sets.iconify.design/healthicons/)

## Installation

```bash
npm install github:iconify/icons-vue#healthicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/healthicons/cold-chain';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/healthicons/emergency-post';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/healthicons/asthma-outline';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
