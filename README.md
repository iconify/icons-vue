**Nimbus**

Author: [Linkedstore S.A.](https://github.com/cyberalien/nimbus-icons)

License: [MIT](https://github.com/cyberalien/nimbus-icons/blob/main/LICENSE)

Browse all icons: [preview Nimbus on Iconify](https://icon-sets.iconify.design/nimbus/)

## Installation

```bash
npm install github:iconify/icons-vue#nimbus
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nimbus/barcode';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nimbus/mail';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nimbus/calendar';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
