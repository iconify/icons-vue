**Medical Icons**

Author: [Samuel Frémondière](https://github.com/samcome/webfont-medical-icons)

License: [MIT](https://github.com/samcome/webfont-medical-icons/blob/master/LICENSE)

Browse all icons: [preview Medical Icons on Iconify](https://icon-sets.iconify.design/medical-icon/)

## Installation

```bash
npm install github:iconify/icons-vue#medical-icon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/medical-icon/i-care-staff-area';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/medical-icon/i-nursery';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/medical-icon/immunizations';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
