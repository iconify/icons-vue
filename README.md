## Installation

```bash
npm install github:iconify/icons-vue#emojione-v1
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/emojione-v1/face-savoring-food';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/emojione-v1/panda-face';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
