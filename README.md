**Line Awesome**

Author: [Icons8](https://github.com/icons8/line-awesome)

License: [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)

Browse all icons: [preview Line Awesome on Iconify](https://icon-sets.iconify.design/la/)

## Installation

```bash
npm install github:iconify/icons-vue#la
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/la/archive-solid';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/la/female-solid';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/la/check-circle';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
