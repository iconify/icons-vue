# @iconify-vue/meteocons

**Meteocons**

Author: [Bas Milius](https://github.com/basmilius/weather-icons)

License: [MIT](https://github.com/basmilius/weather-icons/blob/dev/LICENSE)

Browse all icons: [preview Meteocons on Iconify](https://icon-sets.iconify.design/meteocons/)

## Installation

```bash
npm install github:iconify/icons-vue#meteocons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/meteocons/hurricane-fill';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/meteocons/sunrise-fill';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
