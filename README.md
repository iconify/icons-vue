License: [MIT](https://github.com/dukestreetstudio/zondicons/blob/master/LICENSE)

Browse all icons: [preview Zondicons on Iconify](https://icon-sets.iconify.design/zondicons/)

## Installation

```bash
npm install github:iconify/icons-vue#zondicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/zondicons/copy';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/zondicons/hand-stop';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/zondicons/mouse';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
