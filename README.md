Browse all icons: **[Preview CoreUI Brands](https://icon-sets.iconify.design/cib/)**

## Installation

```bash
npm install github:iconify/icons-vue#cib
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/cib/cc-amazon-pay';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/cib/hotjar';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/cib/open-id';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
