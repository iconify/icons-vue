## Installation

```bash
npm install github:iconify/icons-vue#icon-park
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/icon-park/add-one';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/icon-park/english-mustache';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
