Browse all icons: [preview Pullo Icons on Iconify](https://icon-sets.iconify.design/pullo/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#pullo
```

or
```bash
npm install github:iconify/icons-vue#pullo
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pullo/file-check';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pullo/turtle-fill';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pullo/chart-area-duotone';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
