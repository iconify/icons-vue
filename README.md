Browse all icons: [preview NoviAir on Iconify](https://icon-sets.iconify.design/noviair/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#noviair
```

or
```bash
npm install github:iconify/icons-vue#noviair
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/noviair/wand';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/noviair/menu';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/noviair/summit';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
