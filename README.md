License: [Apache 2.0](https://github.com/Iconscout/unicons/blob/master/LICENSE)

Browse all icons: [preview Unicons Monochrome on Iconify](https://icon-sets.iconify.design/uim/)

## Installation

```bash
npm install github:iconify/icons-vue#uim
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/uim/airplay';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/uim/circle-layer';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/uim/lock-access';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
