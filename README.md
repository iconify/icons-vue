Browse all icons: [preview Innowatio Font on Iconify](https://icon-sets.iconify.design/iwwa/)

## Installation

```bash
npm install github:iconify/icons-vue#iwwa
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iwwa/tag';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iwwa/settings';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iwwa/connection-o';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
