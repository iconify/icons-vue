Browse all icons: [preview Qlementine Icons on Iconify](https://icon-sets.iconify.design/qlementine-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#qlementine-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/qlementine-icons/windows-16';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/qlementine-icons/check-tick-small-16';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/qlementine-icons/speaker-0-16';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
