**Lsicon**

Author: [Wis Design](https://www.lsicon.com/)

License: [MIT](https://github.com/wisdesignsystem/lsicon/blob/main/LICENSE)

Browse all icons: [preview Lsicon on Iconify](https://icon-sets.iconify.design/lsicon/)

## Installation

```bash
npm install github:iconify/icons-vue#lsicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lsicon/pointer-outline';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lsicon/column-filled';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lsicon/vip-outline';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
