Browse all icons: **[Preview Devicon Plain](https://icon-sets.iconify.design/devicon-plain/)**

## Installation

```bash
npm install github:iconify/icons-vue#devicon-plain
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/devicon-plain/kotlin';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/devicon-plain/bulma';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/devicon-plain/logstash';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
