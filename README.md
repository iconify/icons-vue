Browse all icons: [preview Pixel Icon on Iconify](https://icon-sets.iconify.design/pixel/)

## Installation

```bash
npm install github:iconify/icons-vue#pixel
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pixel/folder-solid';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pixel/message';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pixel/bullet-list';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
