# @iconify-vue/simple-line-icons

**Simple line icons**

Author: [Sabbir Ahmed](https://github.com/thesabbir/simple-line-icons)

License: [MIT](https://github.com/thesabbir/simple-line-icons/blob/master/LICENSE.md)

Browse all icons: [preview Simple line icons on Iconify](https://icon-sets.iconify.design/simple-line-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#simple-line-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/simple-line-icons/bubbles';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/simple-line-icons/camrecorder';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/simple-line-icons/cloud-upload';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
