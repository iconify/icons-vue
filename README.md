License: [ISC](https://github.com/applifted/lucide-extended/blob/main/LICENSE)

Browse all icons: [preview Lucide Extended on Iconify](https://icon-sets.iconify.design/lucide-extended/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#lucide-extended
```

or
```bash
npm install github:iconify/icons-vue#lucide-extended
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide-extended/circle-check-filled';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide-extended/award-duotone';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lucide-extended/house-filled';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
