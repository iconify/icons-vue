Browse all icons: [preview with icons Suite on Iconify](https://icon-sets.iconify.design/withicons-suite/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#withicons-suite
```

or
```bash
npm install github:iconify/icons-vue#withicons-suite
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/withicons-suite/home';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/withicons-suite/search';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
