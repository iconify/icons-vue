Browse all icons: [preview Logos free icons on Iconify](https://icon-sets.iconify.design/streamline-logos/)

## Installation

```bash
npm install github:iconify/icons-vue#streamline-logos
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-logos/microsoft-windows-logo-2';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-logos/unspash-logo-solid';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-logos/patreon-logo';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
