Author: [IconMind](https://github.com/Iconmind/iconmind)

License: [MIT](https://github.com/Iconmind/iconmind/blob/main/LICENSE)

Browse all icons: [preview IconMind on Iconify](https://icon-sets.iconify.design/iconmind/)

## Installation

```bash
npm install github:iconify/icons-vue#iconmind
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconmind/agent-outline-regular';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconmind/vector-database-duotone-thin';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconmind/stub-tool-outline-bold';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
