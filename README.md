Browse all icons: [preview Struq Icons on Iconify](https://icon-sets.iconify.design/struq/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#struq
```

or
```bash
npm install github:iconify/icons-vue#struq
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/struq/home';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/struq/search';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/struq/settings';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
