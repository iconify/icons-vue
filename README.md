Browse all icons: [preview Energy Icons on Iconify](https://icon-sets.iconify.design/energy-icons/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#energy-icons
```

or
```bash
npm install github:iconify/icons-vue#energy-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/energy-icons/hex-key-48';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/energy-icons/bookmark-48';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/energy-icons/brackets-48';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
