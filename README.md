## Installation

```bash
npm install gitlab:iconify-icons/vue#devicon
```

or
```bash
npm install github:iconify/icons-vue#devicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/devicon/windows8';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/devicon/tensorflow';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
