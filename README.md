Browse all icons: [preview SVG Spinners on Iconify](https://icon-sets.iconify.design/svg-spinners/)

## Installation

```bash
npm install github:iconify/icons-vue#svg-spinners
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/svg-spinners/tadpole';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/svg-spinners/pulse';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/svg-spinners/3-dots-rotate';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
