# @iconify-vue/prime

**Prime Icons**

Author: [PrimeTek](https://github.com/primefaces/primeicons)

License: [MIT](https://github.com/primefaces/primeicons/blob/master/LICENSE)

Browse all icons: [preview Prime Icons on Iconify](https://icon-sets.iconify.design/prime/)

## Installation

```bash
npm install github:iconify/icons-vue#prime
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/prime/book';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/prime/telegram';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/prime/volume-off';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
