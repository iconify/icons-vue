**Pixel free icons**

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Pixel free icons on Iconify](https://icon-sets.iconify.design/streamline-pixel/)

## Installation

```bash
npm install github:iconify/icons-vue#streamline-pixel
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-pixel/shopping-shipping-bag-1';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-pixel/interface-essential-battery';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-pixel/social-rewards-flag';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
