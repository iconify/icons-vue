# @iconify-vue/thesvg-color

**theSVG Color**

Author: [thesvg.org](https://github.com/glincker/thesvg)

License: [MIT](https://github.com/glincker/thesvg/blob/main/LICENSE)

Browse all icons: [preview theSVG Color on Iconify](https://icon-sets.iconify.design/thesvg-color/)

## Installation

```bash
npm install github:iconify/icons-vue#thesvg-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/thesvg-color/verizon';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/thesvg-color/mitsubishi';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
