# @iconify-vue/stash

**Stash Icons**

Author: [Pingback LLC](https://github.com/stash-ui/icons)

License: [MIT](https://github.com/stash-ui/icons/blob/master/LICENSE)

Browse all icons: [preview Stash Icons on Iconify](https://icon-sets.iconify.design/stash/)

## Installation

```bash
npm install github:iconify/icons-vue#stash
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/stash/cloud-solid';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/stash/clock-duotone';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/stash/search-duotone';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
