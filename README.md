## Installation

```bash
npm install github:iconify/icons-vue#catppuccin
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/catppuccin/folder';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/catppuccin/nuxt';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
