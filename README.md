Browse all icons: [Preview Glyphs](https://icon-sets.iconify.design/glyphs/)

## Installation

```bash
npm install github:iconify/icons-vue#glyphs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/glyphs/mouse-2-bold';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/glyphs/object-select';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/glyphs/comment-1-duo';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
