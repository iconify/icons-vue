## Installation

```bash
npm install gitlab:iconify-icons/vue#material-symbols
```

or
```bash
npm install github:iconify/icons-vue#material-symbols
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/material-symbols/downloading';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/material-symbols/privacy-tip';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/material-symbols/filter-drama-outline';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
