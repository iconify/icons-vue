Browse all icons: [preview Siemens Industrial Experience Icons on Iconify](https://icon-sets.iconify.design/ix/)

## Installation

```bash
npm install github:iconify/icons-vue#ix
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ix/notification-filled';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ix/home-filled';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ix/panel-ipc';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
