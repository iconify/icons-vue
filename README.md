## Installation

```bash
npm install github:iconify/icons-vue#solar
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/solar/magnifier-zoom-out-broken';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/solar/armchair-2-bold-duotone';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/solar/traffic-economy-line-duotone';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
