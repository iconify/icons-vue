## Installation

```bash
npm install gitlab:iconify-icons/vue#wordpress
```

or
```bash
npm install github:iconify/icons-vue#wordpress
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wordpress/home';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wordpress/pencil';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wordpress/corner-top-right';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
