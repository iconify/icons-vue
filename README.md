Browse all icons: **[Preview Feather Icon](https://icon-sets.iconify.design/fe/)**

## Installation

```bash
npm install github:iconify/icons-vue#fe
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fe/add-cart';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fe/comments';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fe/link-external';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
