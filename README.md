Browse all icons: **[Preview Boxicons Brands](https://icon-sets.iconify.design/bxl/)**

## Installation

```bash
npm install github:iconify/icons-vue#bxl
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bxl/patreon';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bxl/adobe';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bxl/vuejs';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
