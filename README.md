**Google Material Icons**

Author: [Material Design Authors](https://github.com/material-icons/material-icons)

License: [Apache 2.0](https://github.com/material-icons/material-icons/blob/master/LICENSE)

Browse all icons: [preview Google Material Icons on Iconify](https://icon-sets.iconify.design/ic/)

## Installation

```bash
npm install github:iconify/icons-vue#ic
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ic/baseline-notifications-active';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ic/outline-person-outline';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ic/twotone-videocam-off';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
