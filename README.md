# @iconify-vue/radix-icons

**Radix Icons**

Author: [WorkOS](https://github.com/radix-ui/icons)

License: [MIT](https://github.com/radix-ui/icons/blob/master/LICENSE)

Browse all icons: [preview Radix Icons on Iconify](https://icon-sets.iconify.design/radix-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#radix-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/radix-icons/width';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/radix-icons/checkbox';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/radix-icons/code';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
