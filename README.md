# @iconify-vue/logos

**SVG Logos**

Author: [Gil Barbara](https://github.com/gilbarbara/logos)

License: [CC0](https://raw.githubusercontent.com/gilbarbara/logos/master/LICENSE.txt)

Browse all icons: [preview SVG Logos on Iconify](https://icon-sets.iconify.design/logos/)

## Installation

```bash
npm install github:iconify/icons-vue#logos
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/logos/npm-icon';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/logos/uikit';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
