# @iconify-vue/codex

**CodeX Icons**

Author: [CodeX](https://github.com/davidabou/icons)

License: [MIT](https://github.com/codex-team/icons/blob/master/LICENSE)

Browse all icons: [preview CodeX Icons on Iconify](https://icon-sets.iconify.design/codex/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#codex
```

or
```bash
npm install github:iconify/icons-vue#codex
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/codex/align-left';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/codex/table-with-headings';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/codex/heading';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
