Browse all icons: [preview OOUI on Iconify](https://icon-sets.iconify.design/ooui/)

## Installation

```bash
npm install github:iconify/icons-vue#ooui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ooui/search';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ooui/share';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ooui/restore';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
