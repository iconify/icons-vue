Browse all icons: **[Preview Element Plus](https://icon-sets.iconify.design/ep/)**

## Installation

```bash
npm install github:iconify/icons-vue#ep
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ep/home-filled';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ep/partly-cloudy';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ep/avatar';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
