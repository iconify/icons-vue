## Installation

```bash
npm install gitlab:iconify-icons/vue#coolicons
```

or
```bash
npm install github:iconify/icons-vue#coolicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/coolicons/battery-empty-duotone-round';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/coolicons/venus-fill-round';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/coolicons/apple-logo-duocolor-round';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
