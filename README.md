Browse all icons: [preview Material Line Icons on Iconify](https://icon-sets.iconify.design/line-md/)

## Installation

```bash
npm install github:iconify/icons-vue#line-md
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/line-md/loading-twotone-loop';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/line-md/beer-alt-twotone-loop';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/line-md/image-twotone';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
