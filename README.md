## Installation

```bash
npm install gitlab:iconify-icons/vue#pinhead
```

or
```bash
npm install github:iconify/icons-vue#pinhead
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pinhead/a-frame-tent';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pinhead/bird';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/pinhead/boat-on-trailer';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
