Browse all icons: [preview Mage Icons on Iconify](https://icon-sets.iconify.design/mage/)

## Installation

```bash
npm install github:iconify/icons-vue#mage
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mage/chart-25';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mage/music-fill';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mage/coin-a-fill';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
