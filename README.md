## Installation

```bash
npm install github:iconify/icons-vue#bitcoin-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bitcoin-icons/exchange-outline';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bitcoin-icons/brush-filled';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bitcoin-icons/satoshi-v3-outline';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
