**Material Design Light**

Author: [Pictogrammers](https://github.com/Templarian/MaterialDesignLight)

License: [Open Font License](https://github.com/Templarian/MaterialDesignLight/blob/master/LICENSE.md)

Browse all icons: [preview Material Design Light on Iconify](https://icon-sets.iconify.design/mdi-light/)

## Installation

```bash
npm install github:iconify/icons-vue#mdi-light
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mdi-light/cart';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mdi-light/bell';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mdi-light/login';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
