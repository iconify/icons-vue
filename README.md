# @iconify-vue/iconaut

**Iconaut**

Author: [Iconaut](https://github.com/iconaut-design/icons)

License: [MIT](https://github.com/iconaut-design/icons/blob/main/LICENSE)

Browse all icons: [preview Iconaut on Iconify](https://icon-sets.iconify.design/iconaut/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#iconaut
```

or
```bash
npm install github:iconify/icons-vue#iconaut
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconaut/award-duo';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconaut/play';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconaut/bookmark-duo';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
