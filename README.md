License: [MIT](https://github.com/LineiconsHQ/Lineicons/blob/main/LICENSE.md)

Browse all icons: [preview Lineicons on Iconify](https://icon-sets.iconify.design/lineicons/)

## Installation

```bash
npm install github:iconify/icons-vue#lineicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lineicons/check';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lineicons/vuejs';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/lineicons/star-fat';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
