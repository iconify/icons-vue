# @iconify-vue/temaki

**Temaki**

Author: [Bryan Housel](https://github.com/rapideditor/temaki)

License: [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview Temaki on Iconify](https://icon-sets.iconify.design/temaki/)

## Installation

```bash
npm install github:iconify/icons-vue#temaki
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/temaki/milestone';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/temaki/elevator';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/temaki/storage';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
