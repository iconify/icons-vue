**Iconito Food**

Author: [Iconito](https://github.com/iconi-to/free-food)

License: [MIT](https://github.com/iconi-to/free-food/blob/main/LICENSE)

Browse all icons: [preview Iconito Food on Iconify](https://icon-sets.iconify.design/iconito/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#iconito
```

or
```bash
npm install github:iconify/icons-vue#iconito
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconito/ice-cream';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconito/banana';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
