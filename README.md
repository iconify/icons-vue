# @iconify-vue/material-icon-theme

**Material Icon Theme**

Author: [Material Extensions](https://github.com/material-extensions/vscode-material-icon-theme)

License: [MIT](https://github.com/material-extensions/vscode-material-icon-theme/blob/main/LICENSE)

Browse all icons: [preview Material Icon Theme on Iconify](https://icon-sets.iconify.design/material-icon-theme/)

## Installation

```bash
npm install github:iconify/icons-vue#material-icon-theme
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/material-icon-theme/zip';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/material-icon-theme/email';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
