Browse all icons: **[Preview Flat UI Icons](https://icon-sets.iconify.design/flat-ui/)**

## Installation

```bash
npm install github:iconify/icons-vue#flat-ui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/flat-ui/map';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/flat-ui/graph';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
