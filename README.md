Browse all icons: [preview NRK Core Icons on Iconify](https://icon-sets.iconify.design/nrk/)

## Installation

```bash
npm install github:iconify/icons-vue#nrk
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nrk/lyn';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nrk/edit';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/nrk/mening';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
