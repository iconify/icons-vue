Browse all icons: [preview Pico-icon on Iconify](https://icon-sets.iconify.design/picon/)

## Installation

```bash
npm install github:iconify/icons-vue#picon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/picon/bookmark';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/picon/rewind';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/picon/folder';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
