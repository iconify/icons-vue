**Skill Icons**

Author: [tandpfun](https://github.com/tandpfun/skill-icons)

License: [MIT](https://github.com/tandpfun/skill-icons/blob/main/LICENSE)

Browse all icons: [preview Skill Icons on Iconify](https://icon-sets.iconify.design/skill-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#skill-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/skill-icons/markdown-light';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/skill-icons/vuejs-dark';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
