Browse all icons: [preview with icons Liquid on Iconify](https://icon-sets.iconify.design/withicons-liquid/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#withicons-liquid
```

or
```bash
npm install github:iconify/icons-vue#withicons-liquid
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/withicons-liquid/home';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/withicons-liquid/search';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
