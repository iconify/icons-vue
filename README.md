## Installation

```bash
npm install gitlab:iconify-icons/vue#vscode-icons
```

or
```bash
npm install github:iconify/icons-vue#vscode-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/vscode-icons/file-type-actionscript2';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/vscode-icons/file-type-json';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
