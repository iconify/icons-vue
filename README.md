Browse all icons: [preview Memes on Iconify](https://icon-sets.iconify.design/streamline-memes/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#streamline-memes
```

or
```bash
npm install github:iconify/icons-vue#streamline-memes
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-memes/angry-face';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-memes/pop-cat';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-memes/pop-cat';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
