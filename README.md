Browse all icons: [preview Rivet Icons on Iconify](https://icon-sets.iconify.design/rivet-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#rivet-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/rivet-icons/lightning';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/rivet-icons/credit-card-solid';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/rivet-icons/pause';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
