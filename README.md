Icon set prefix: **fluent-color**

Icon set name: **Fluent UI System Color Icons**

Author: **Microsoft Corporation**

License: **[MIT](https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE)**

Repository: **https://github.com/microsoft/fluentui-system-icons**

Browse all icons: **[Preview Fluent UI System Color Icons](https://icon-sets.iconify.design/fluent-color/)**

## Installation

```bash
npm install github:iconify/icons-vue#fluent-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fluent-color/mic-20';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fluent-color/alert-32';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
