# @iconify-vue/icons8

**Icons8 Windows 10 Icons**

Author: [Icons8](https://github.com/icons8/windows-10-icons)

License: MIT

Browse all icons: [preview Icons8 Windows 10 Icons on Iconify](https://icon-sets.iconify.design/icons8/)

## Installation

```bash
npm install github:iconify/icons-vue#icons8
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/icons8/checked';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/icons8/create-new';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/icons8/group';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
