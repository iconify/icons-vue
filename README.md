Browse all icons: [preview Griddy Icons on Iconify](https://icon-sets.iconify.design/griddy-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#griddy-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/griddy-icons/annotation';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/griddy-icons/twitch-filled';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/griddy-icons/chart-bar-up-alt';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
