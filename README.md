Author: [Dmitry Baranovskiy](https://github.com/dmitrybaranovskiy/raphael)

Browse all icons: [preview Raphael on Iconify](https://icon-sets.iconify.design/raphael/)

## Installation

```bash
npm install github:iconify/icons-vue#raphael
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/raphael/home';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/raphael/cloud';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/raphael/parent';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
