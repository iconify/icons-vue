Browse all icons: [preview Kubernetes Icons on Iconify](https://icon-sets.iconify.design/k8s/)

## Installation

```bash
npm install github:iconify/icons-vue#k8s
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/k8s/deployment';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/k8s/pod';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
