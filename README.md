License: [MIT](https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE)

Browse all icons: [preview Fluent Emoji on Iconify](https://icon-sets.iconify.design/fluent-emoji/)

## Installation

```bash
npm install github:iconify/icons-vue#fluent-emoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fluent-emoji/avocado';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/fluent-emoji/ticket';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
