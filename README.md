# @iconify-vue/keyline-icons

**Keyline Icons**

Author: [Keyline Icons](https://github.com/keyline-icons/keyline-icons)

License: [MIT](https://github.com/keyline-icons/keyline-icons/blob/main/LICENSE)

Browse all icons: [preview Keyline Icons on Iconify](https://icon-sets.iconify.design/keyline-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#keyline-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/keyline-icons/arrow-up-narrow-wide-duotone';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/keyline-icons/credit-card-fill';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/keyline-icons/upload';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
