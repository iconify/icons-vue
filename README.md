License: [MIT](https://github.com/artcoholic/akar-icons/blob/master/LICENSE)

Browse all icons: [preview Akar Icons on Iconify](https://icon-sets.iconify.design/akar-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#akar-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/akar-icons/paper';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/akar-icons/pencil';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/akar-icons/location';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
