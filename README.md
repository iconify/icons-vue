# @iconify-vue/streamline-plump

**Plump free icons**

Author: [Streamline](https://github.com/webalys-hq/streamline-vectors)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Plump free icons on Iconify](https://icon-sets.iconify.design/streamline-plump/)

## Installation

```bash
npm install github:iconify/icons-vue#streamline-plump
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-plump/smiley-indiferent';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-plump/music-note-2';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-plump/web';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
