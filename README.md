Browse all icons: [preview Teenyicons on Iconify](https://icon-sets.iconify.design/teenyicons/)

## Installation

```bash
npm install github:iconify/icons-vue#teenyicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/teenyicons/face-id-solid';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/teenyicons/user-outline';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/teenyicons/page-break-outline';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
