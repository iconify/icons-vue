Browse all icons: [preview Octicons on Iconify](https://icon-sets.iconify.design/octicon/)

## Installation

```bash
npm install github:iconify/icons-vue#octicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/octicon/alert-24';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/octicon/bell-slash-24';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/octicon/hourglass-24';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
