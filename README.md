Icon set prefix: **foundation**

Icon set name: **Foundation**

Author: **Zurb**

License: **MIT**

Repository: **https://github.com/zurb/foundation-icon-fonts**

Browse all icons: **[Preview Foundation](https://icon-sets.iconify.design/foundation/)**

## Installation

```bash
npm install github:iconify/icons-vue#foundation
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/foundation/graph-trend';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/foundation/indent-more';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/foundation/lock';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
