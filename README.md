# @iconify-vue/hugeicons

**Huge Icons**

Author: [Hugeicons](https://icon-sets.iconify.design/icon-sets/hugeicons/)

License: MIT

Browse all icons: [preview Huge Icons on Iconify](https://icon-sets.iconify.design/hugeicons/)

## Installation

```bash
npm install github:iconify/icons-vue#hugeicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/hugeicons/analytics-up';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/hugeicons/android';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/hugeicons/search-02';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
