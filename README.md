# @iconify-vue/reicon

**Reicon**

Author: [REICON](https://github.com/dqev/reicon)

License: [MIT](https://github.com/dqev/reicon/blob/main/LICENSE)

Browse all icons: [preview Reicon on Iconify](https://icon-sets.iconify.design/reicon/)

## Installation

```bash
npm install github:iconify/icons-vue#reicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/reicon/ruler4';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/reicon/cart-add2-filled';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/reicon/search-normal2';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
