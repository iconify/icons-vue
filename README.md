Browse all icons: [preview OpenMoji on Iconify](https://icon-sets.iconify.design/openmoji/)

## Installation

```bash
npm install github:iconify/icons-vue#openmoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/openmoji/bicycle';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/openmoji/bow-and-arrow';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
