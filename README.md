# @iconify-vue/gridicons

**Gridicons**

Author: [Automattic](https://github.com/Automattic/gridicons)

License: [GPL 2.0](https://github.com/Automattic/gridicons/blob/trunk/LICENSE.md)

Browse all icons: [preview Gridicons on Iconify](https://icon-sets.iconify.design/gridicons/)

## Installation

```bash
npm install github:iconify/icons-vue#gridicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/gridicons/code';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/gridicons/multiple-users';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/gridicons/types';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
