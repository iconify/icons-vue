## Installation

```bash
npm install github:iconify/icons-vue#iconamoon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconamoon/shield-off-thin';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconamoon/lightning-1-duotone';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconamoon/player-previous-fill';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
