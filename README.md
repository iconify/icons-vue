# @iconify-vue/maki

**Maki**

Author: [Mapbox](https://github.com/mapbox/maki)

License: [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview Maki on Iconify](https://icon-sets.iconify.design/maki/)

## Installation

```bash
npm install github:iconify/icons-vue#maki
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/maki/entrance-alt1';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/maki/clothing-store';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/maki/grocery';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
