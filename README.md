# @iconify-vue/twemoji

**Twitter Emoji**

Author: [Twitter](https://github.com/jdecked/twemoji)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Twitter Emoji on Iconify](https://icon-sets.iconify.design/twemoji/)

## Installation

```bash
npm install github:iconify/icons-vue#twemoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/twemoji/anguished-face';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/twemoji/duck';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
