**Cyber color icons**

Author: [Streamline](https://github.com/webalys-hq/streamline-vectors)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Cyber color icons on Iconify](https://icon-sets.iconify.design/streamline-cyber-color/)

## Installation

```bash
npm install github:iconify/icons-vue#streamline-cyber-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-cyber-color/shopping-basket-3';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-cyber-color/command-2';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
