# @iconify-vue/weui

**WeUI Icon**

Author: [WeUI](https://github.com/weui/weui-icon)

License: MIT

Browse all icons: [preview WeUI Icon on Iconify](https://icon-sets.iconify.design/weui/)

## Installation

```bash
npm install github:iconify/icons-vue#weui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/weui/search-outlined';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/weui/clip-filled';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/weui/done-filled';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
