**Remix Icon**

Author: [Remix Design](https://github.com/cyberalien/RemixIcon)

License: [Apache 2.0](https://github.com/cyberalien/RemixIcon/blob/master/License)

Browse all icons: [preview Remix Icon on Iconify](https://icon-sets.iconify.design/ri/)

## Installation

```bash
npm install github:iconify/icons-vue#ri
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ri/lock-2-line';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ri/mark-pen-fill';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ri/moon-line';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
