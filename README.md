Author: **The Bootstrap Authors**

License: **[MIT](https://github.com/twbs/icons/blob/main/LICENSE.md)**

Repository: **https://github.com/twbs/icons**

Browse all icons: **[Preview Bootstrap Icons](https://icon-sets.iconify.design/bi/)**

## Installation

```bash
npm install github:iconify/icons-vue#bi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bi/graph-up';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bi/card-image';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bi/code-slash';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
