## Installation

```bash
npm install github:iconify/icons-vue#bpmn
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bpmn/intermediate-event-catch-non-interrupting-escalation';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bpmn/user';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/bpmn/lane-insert-above';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
