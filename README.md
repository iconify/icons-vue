# @iconify-vue/material-symbols-light

**Material Symbols Light**

Author: [Google](https://github.com/google/material-design-icons)

License: [Apache 2.0](https://github.com/google/material-design-icons/blob/master/LICENSE)

Browse all icons: [preview Material Symbols Light on Iconify](https://icon-sets.iconify.design/material-symbols-light/)

## Installation

```bash
npm install github:iconify/icons-vue#material-symbols-light
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/material-symbols-light/downloading';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/material-symbols-light/privacy-tip';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/material-symbols-light/filter-drama-outline';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
