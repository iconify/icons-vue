Browse all icons: [preview Humbleicons on Iconify](https://icon-sets.iconify.design/humbleicons/)

## Installation

```bash
npm install github:iconify/icons-vue#humbleicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/humbleicons/aid';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/humbleicons/droplet';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/humbleicons/rss';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
