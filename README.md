Browse all icons: **[Preview File Icons](https://icon-sets.iconify.design/file-icons/)**

## Installation

```bash
npm install github:iconify/icons-vue#file-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/file-icons/adobe';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/file-icons/chartjs';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/file-icons/dom';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
