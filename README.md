# @iconify-vue/iconoven

**IconOven**

Author: [Appic Marketing](https://www.npmjs.com/package/@iconoven/svg)

License: MIT

Browse all icons: [preview IconOven on Iconify](https://icon-sets.iconify.design/iconoven/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#iconoven
```

or
```bash
npm install github:iconify/icons-vue#iconoven
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconoven/bell';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconoven/home';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/iconoven/credit-card';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
