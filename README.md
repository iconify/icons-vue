Browse all icons: **[Preview Carbon](https://icon-sets.iconify.design/carbon/)**

## Installation

```bash
npm install github:iconify/icons-vue#carbon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/carbon/user-certification';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/carbon/humidity';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/carbon/edit-off';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
