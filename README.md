**SidekickIcons**

Author: [Andri Soone](https://github.com/ndri/sidekickicons)

License: [MIT](https://github.com/ndri/sidekickicons/blob/master/LICENSE)

Browse all icons: [preview SidekickIcons on Iconify](https://icon-sets.iconify.design/sidekickicons/)

## Installation

```bash
npm install github:iconify/icons-vue#sidekickicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/sidekickicons/crown';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/sidekickicons/blockquote';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/sidekickicons/compass';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
