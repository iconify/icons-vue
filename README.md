Browse all icons: [preview EVicons on Iconify](https://icon-sets.iconify.design/evicons/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#evicons
```

or
```bash
npm install github:iconify/icons-vue#evicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/evicons/marker-queue';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/evicons/driving-range';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/evicons/plug-in-hybrid';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
