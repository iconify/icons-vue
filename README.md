Browse all icons: [preview andrsrxn/icons on Iconify](https://icon-sets.iconify.design/andrsrxn/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#andrsrxn
```

or
```bash
npm install github:iconify/icons-vue#andrsrxn
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/andrsrxn/agent';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/andrsrxn/hashtag';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/andrsrxn/box';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
