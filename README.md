## Installation

```bash
npm install gitlab:iconify-icons/vue#xero-emoji
```

or
```bash
npm install github:iconify/icons-vue#xero-emoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/xero-emoji/paperclip';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/xero-emoji/ladder';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
