Browse all icons: [preview Simple Icons on Iconify](https://icon-sets.iconify.design/simple-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#simple-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/simple-icons/wise';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/simple-icons/framer';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/simple-icons/vuetify';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
