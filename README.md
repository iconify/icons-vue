# @iconify-vue/ph

**Phosphor**

Author: [Phosphor Icons](https://github.com/phosphor-icons/core)

License: [MIT](https://github.com/phosphor-icons/core/blob/main/LICENSE)

Browse all icons: [preview Phosphor on Iconify](https://icon-sets.iconify.design/ph/)

## Installation

```bash
npm install github:iconify/icons-vue#ph
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ph/folder-open-duotone';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ph/check-square-offset-thin';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/ph/pencil-line-fill';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
