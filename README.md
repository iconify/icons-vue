# @iconify-vue/tdesign

**TDesign Icons**

Author: [TDesign](https://github.com/Tencent/tdesign-icons)

License: [MIT](https://github.com/Tencent/tdesign-icons/blob/main/LICENSE)

Browse all icons: [preview TDesign Icons on Iconify](https://icon-sets.iconify.design/tdesign/)

## Installation

```bash
npm install github:iconify/icons-vue#tdesign
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/tdesign/activity';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/tdesign/doge';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/tdesign/dam';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
