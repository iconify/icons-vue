Browse all icons: [preview Tabler Icons on Iconify](https://icon-sets.iconify.design/tabler/)

## Installation

```bash
npm install github:iconify/icons-vue#tabler
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/tabler/alien';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/tabler/device-desktop';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/tabler/photo';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
