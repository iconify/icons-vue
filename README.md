**Freehand free icons**

Author: [Streamline](https://github.com/webalys-hq/streamline-vectors)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Freehand free icons on Iconify](https://icon-sets.iconify.design/streamline-freehand/)

## Installation

```bash
npm install github:iconify/icons-vue#streamline-freehand
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-freehand/terminal';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-freehand/cursor-speed-1';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-freehand/lock-cancel-slash';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
