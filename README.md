## Installation

```bash
npm install gitlab:iconify-icons/vue#garden
```

or
```bash
npm install github:iconify/icons-vue#garden
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/garden/asterisk-stroke-12';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/garden/bookmark-fill-12';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/garden/moon-fill-12';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
