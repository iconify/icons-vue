Browse all icons: [preview Vadivam on Iconify](https://icon-sets.iconify.design/vadivam/)

## Installation

```bash
npm install github:iconify/icons-vue#vadivam
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/vadivam/axis-3d';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/vadivam/flag';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/vadivam/app-window-mac';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
