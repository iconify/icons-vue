**Open Iconic**

Author: [Iconic](https://github.com/iconic/open-iconic)

License: [MIT](https://github.com/iconic/open-iconic/blob/master/ICON-LICENSE)

Browse all icons: [preview Open Iconic on Iconify](https://icon-sets.iconify.design/oi/)

## Installation

```bash
npm install github:iconify/icons-vue#oi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/oi/bug';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/oi/bullhorn';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/oi/chat';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
