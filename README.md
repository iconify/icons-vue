Browse all icons: [preview Guidance on Iconify](https://icon-sets.iconify.design/guidance/)

## Installation

```bash
npm install github:iconify/icons-vue#guidance
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/guidance/smoking-area';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/guidance/playground';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/guidance/glass';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
