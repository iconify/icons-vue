Browse all icons: [preview IcoMoon Free on Iconify](https://icon-sets.iconify.design/icomoon-free/)

## Installation

```bash
npm install github:iconify/icons-vue#icomoon-free
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/icomoon-free/bubbles3';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/icomoon-free/forward';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/icomoon-free/volume-medium';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
