Browse all icons: [preview Oreo Doodle Icons on Iconify](https://icon-sets.iconify.design/doodle-icons/)

## Installation

```bash
npm install gitlab:iconify-icons/vue#doodle-icons
```

or
```bash
npm install github:iconify/icons-vue#doodle-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/doodle-icons/heart';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/doodle-icons/home';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/doodle-icons/bell';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
