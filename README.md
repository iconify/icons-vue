# @iconify-vue/wpf

**Icons8 Windows 8 Icons**

Author: [Icons8](https://github.com/icons8/WPF-UI-Framework)

License: MIT

Browse all icons: [preview Icons8 Windows 8 Icons on Iconify](https://icon-sets.iconify.design/wpf/)

## Installation

```bash
npm install github:iconify/icons-vue#wpf
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wpf/check-file';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wpf/add-image';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/wpf/geo-fence';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
