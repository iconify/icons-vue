Author: [Casper Lourens](https://www.figma.com/community/file/1034432054377533052/Quill-Iconset)

License: [MIT](https://github.com/yourtempo/tempo-quill-icons/blob/main/LICENSE)

Browse all icons: [preview Quill Icons on Iconify](https://icon-sets.iconify.design/quill/)

## Installation

```bash
npm install github:iconify/icons-vue#quill
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/quill/collapse';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/quill/desktop';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/quill/moon';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
