**Ultimate free icons**

Browse all icons: [preview Ultimate free icons on Iconify](https://icon-sets.iconify.design/streamline-ultimate/)

## Installation

```bash
npm install github:iconify/icons-vue#streamline-ultimate
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-ultimate/power-button';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-ultimate/arrow-right';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-ultimate/stairs-descend';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
