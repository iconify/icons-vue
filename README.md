Browse all icons: [preview Grommet Icons on Iconify](https://icon-sets.iconify.design/grommet-icons/)

## Installation

```bash
npm install github:iconify/icons-vue#grommet-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/grommet-icons/user-expert';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/grommet-icons/action';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/grommet-icons/home';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
