## Installation

```bash
npm install github:iconify/icons-vue#circle-flags
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/circle-flags/ee';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/circle-flags/klingon';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
