Browse all icons: [preview Mono Icons on Iconify](https://icon-sets.iconify.design/mi/)

## Installation

```bash
npm install github:iconify/icons-vue#mi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mi/bar-chart';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mi/cloud-upload';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mi/log-out';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
