# @iconify-vue/osmic

**OSM Icons**

Author: [GMGeo](https://github.com/gmgeo/osmic)

License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview OSM Icons on Iconify](https://icon-sets.iconify.design/osmic/)

## Installation

```bash
npm install github:iconify/icons-vue#osmic
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/osmic/post-office-14';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/osmic/elevator-14';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/osmic/pub-14';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
