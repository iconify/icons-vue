## Installation

```bash
npm install gitlab:iconify-icons/vue#meteor-icons
```

or
```bash
npm install github:iconify/icons-vue#meteor-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/meteor-icons/droplet';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/meteor-icons/bolt';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/meteor-icons/flipboard';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
