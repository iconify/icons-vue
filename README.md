# @iconify-vue/streamline-emojis

**Streamline Emojis**

Author: [Streamline](https://github.com/webalys-hq/streamline-vectors)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Streamline Emojis on Iconify](https://icon-sets.iconify.design/streamline-emojis/)

## Installation

```bash
npm install github:iconify/icons-vue#streamline-emojis
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-emojis/crescent-moon';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/streamline-emojis/fire';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
