Browse all icons: [preview ProIcons on Iconify](https://icon-sets.iconify.design/proicons/)

## Installation

```bash
npm install github:iconify/icons-vue#proicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/proicons/code';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/proicons/checkmark';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/proicons/photo-filter';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
