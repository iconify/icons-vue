Author: **WordPress**

License: **[GPL](https://github.com/WordPress/dashicons/blob/master/gpl.txt)**

Repository: **https://github.com/WordPress/dashicons**

Browse all icons: **[Preview Dashicons](https://icon-sets.iconify.design/dashicons/)**

## Installation

```bash
npm install github:iconify/icons-vue#dashicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/dashicons/shortcode';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/dashicons/businessperson';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/dashicons/editor-expand';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
