Browse all icons: [preview uiw icons on Iconify](https://icon-sets.iconify.design/uiw/)

## Installation

```bash
npm install github:iconify/icons-vue#uiw
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/uiw/cut';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/uiw/like-o';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/uiw/download';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
