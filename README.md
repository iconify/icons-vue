**Material Design Icons**

Author: [Pictogrammers](https://github.com/Templarian/MaterialDesign)

License: [Apache 2.0](https://github.com/Templarian/MaterialDesign/blob/master/LICENSE)

Browse all icons: [preview Material Design Icons on Iconify](https://icon-sets.iconify.design/mdi/)

## Installation

```bash
npm install github:iconify/icons-vue#mdi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mdi/account-check';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mdi/bell-alert-outline';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/mdi/calendar-edit';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
