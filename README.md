## Installation

```bash
npm install github:iconify/icons-vue#covid
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/covid/social-distancing-correct-2';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/covid/personal-hygiene-clean-toothpaste';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/covid/vaccine-protection-medicine-pill';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
