**UnJS Logos**

Author: [UnJS](https://github.com/unjs)

License: Apache 2.0

Browse all icons: [preview UnJS Logos on Iconify](https://icon-sets.iconify.design/unjs/)

## Installation

```bash
npm install github:iconify/icons-vue#unjs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/unjs/nitro';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/unjs/jiti';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
