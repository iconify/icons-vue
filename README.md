**Noto Emoji (v1)**

Author: [Google Inc](https://github.com/googlefonts/noto-emoji)

License: [Apache 2.0](https://github.com/googlefonts/noto-emoji/blob/main/svg/LICENSE)

Browse all icons: [preview Noto Emoji (v1) on Iconify](https://icon-sets.iconify.design/noto-v1/)

## Installation

```bash
npm install github:iconify/icons-vue#noto-v1
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/noto-v1/face-with-open-mouth';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/noto-v1/no-entry';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```
