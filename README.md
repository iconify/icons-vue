# @iconify-vue/heroicons

**HeroIcons**

Author: [Refactoring UI Inc](https://github.com/tailwindlabs/heroicons)

License: [MIT](https://github.com/tailwindlabs/heroicons/blob/master/LICENSE)

Browse all icons: [preview HeroIcons on Iconify](https://icon-sets.iconify.design/heroicons/)

## Installation

```bash
npm install github:iconify/icons-vue#heroicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/vue/).

Few usage examples:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/heroicons/camera';
</script>
<template>
  <SampleIcon />
</template>
```

To resize icon, set `width` and/or `height` parameters:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/heroicons/building-library';
</script>
<template>
  <SampleIcon height="1em" />
</template>
```

To change icon color, use style:

```vue
<script setup lang="ts">
import SampleIcon from '@iconify-vue/heroicons/receipt-refund';
</script>
<template>
  <SampleIcon style="color: red;" />
</template>
```
